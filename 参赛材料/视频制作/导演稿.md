## 视觉密度条款（防线框稿 · v2 修订）

1. **全片无静止镜头**：每镜摄像机 settle 后仍以 ~0.6%/镜 单调缓推（CameraRig 持续推进），任意 2s 窗口内必须有可感知运动（唯一例外：片尾末帧呼吸）；镜内元素进出动效错峰。
2. 每镜同屏活跃元素 ≤3：hero 卡 + 一个辅助面板 + 一组标注；辅助面板进场时卡片必须让位且降饱和（退暗 .5），不抢主角。
3. 一镜一动效：镜 5 只有朱圈一个动效；镜 8 打字段禁镜头运动叠加（推进行在打字开始前完成）。
4. 真实截图材料必须 2x 才可推近（本片推近上限 1.5x，素材为 1x 截图 → 推近段一律用 DOM 重建元素或预裁切特写，禁止对整页截图推近超过 1.2x）。
5. 上屏文字全部来自解说稿或界面原文；标注（朱圈/箭头/光标/朱印）风格与产品 UI 拉开一层（衬线注记+朱红），做导览员不做 UI 的一部分。
6. 铁律自检：任意抽一帧必须有底层运动（纸纹 drift / 卡片呼吸 scale 1↔1.012 / 聚光游走）；scene 间靠卡片 morph 接力，禁整页 opacity 硬切。
7. **开场 0-18s 与旁白逐句对应**（用户第一反馈）：镜头语言直接图解台词——「你是谁带的」→群像墙聚焦；「最难换工作」→墙推近；「三十六道菜」→菜名章涌入；「八个字」→收束成简历卡。
8. **纯产品介绍**（用户第二反馈）：全片（解说词/画面/片尾）零 TRAE 字样、零 slogan；片尾只落产品名 + 产品句。
