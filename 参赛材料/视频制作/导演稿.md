## 视觉密度条款（防线框稿）

1. 每镜同屏活跃元素 ≤3：hero 卡 + 一个辅助面板 + 一组标注；辅助面板进场时卡片必须让位且降饱和（退暗 .5），不抢主角。
2. hold/rest 先划预算：每镜末 ≥0.5s 真静止（禁尾漂）；镜 2/3/8 的 push-in 前各留 0.6s 静止「让观众先看到全局」。
3. 一镜一动效：镜 5 只有朱圈一个动效；镜 8 打字段禁镜头运动叠加（推进行在打字开始前完成）。
4. 真实截图材料必须 2x 才可推近（本片推近上限 1.5x，素材为 1x 截图 → 推近段一律用 DOM 重建元素或预裁切特写，禁止对整页截图推近超过 1.2x）。
5. 上屏文字全部来自解说稿或界面原文；标注（朱圈/箭头/光标）风格与产品 UI 拉开一层（衬线注记+朱红），做导览员不做 UI 的一部分。
6. 铁律自检：任意抽一帧必须有底层运动（纸纹 drift / 卡片呼吸 scale 1↔1.012 / 聚光游走）；scene 间靠卡片 morph 接力，禁整页 opacity 硬切。
