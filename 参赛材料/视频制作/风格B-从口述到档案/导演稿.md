## 视觉密度条款（防线框稿）

1. **双联因果唯一**：每镜同屏活跃簇 ≤3（左联文档 + 右联文档 + 一组标注/大字）；辅助面板进场时旧主角必须让位且退暗（.4-.75），不抢因果。
2. **前 15 秒对位公理**：0-15s 内每个画面元素都有旁白词级锚点——声波=「说起手艺」，碎块=「三十年刀工/文思豆腐/二十多个徒弟」，笔=「笔尖悬在纸上」，大字首拍=「他的手艺」（14.76s）；全时段无 >1.2s 无新信息窗口。
3. **hold 预算反转**：与主版相反，本片每镜摄像机恒动（0.5-1.0%/s），镜内动效错峰 0.28-1.2s；唯一成段静止是 107.0-109.36s 片尾末帧（≥1.2s hold，唯一豁免）。
4. **一镜一高潮**：镜 3 只有「航班过线」一个高潮动效；镜 4 字段显影期间摄像机推速降到 0.8%/s，不与词级 pop 叠加抢戏。
5. **真实像素推近上限**：谱页真实截图为 1x 素材 → 只作 292px 内嵌证物不推近；推近段一律 DOM 重建（卡/拆解/来源）。
6. **上屏文字全部来自解说稿或界面原文**；标注（朱圈/箭头/光标/朱批）风格与产品 UI 拉开一层（衬线注记+朱红），做导览员不做 UI 的一部分。
7. **铁律自检**：任意抽帧必有底层运动（纸纹 drift / 声波 idle 微动 / 流程线 dash 漂移 / 卡片呼吸 scale 1↔1.01）；镜间靠文档位置 morph 接力，无整页 opacity 硬切。
