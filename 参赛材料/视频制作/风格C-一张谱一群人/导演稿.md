# 导演稿 · 星厨传承参赛演示片（风格 C：一张谱，一群人）

- 成片规格：1920×1080 · 30fps（seek 渲染）· 109.6s · 解说驱动（voice=XiaoxiaoNeural · rate=-6% · head 0.8 / gap 0.55 / tail 1.4，实测见 `_narration/timeline.json`）
- 视觉骨架：**一张 8900px 宽的「数字师承谱」长卷（宋刻本章法）从 t=0 演到片尾**。镜头是纪录片摄影机：斜置平面（rotateX 8-17° / rotateY -5~-15°）上沿 x 轴单向巡览，每段旁白对应长卷上一处「局部特写」。群像（真实厨师头像 178 张）不是装饰，是主角本体——853 位留影厨师以谱首墙的形式在场。
- 运动契约（与主版「静止定场」路线相反，为解决「前 15 秒太无聊」）：
  1. **每镜 settle 后保持单调推进**：settle（expoOut 1.4s，镜间 morph）完成后，摄像机继续以 dx≈8-46px/s、dz≈+0.2-0.6%/s 线性推进/右移，全片无一处 >2s 静止（唯一例外：片尾末帧 hold ≈1.4s）。
  2. 镜内元素进出全部错峰（tile 点亮 31ms/片、帖子 350ms/帖、徒弟卡 45ms/卡），无一刀切同帧出现。
  3. 底层恒动：纸纹 feTurbulence drift、卷面内容 parallax（camera 移动自带）、暗角呼吸。
- 数字口径：1,238 真实档案 / 853 位有照片 / 262 条可溯师承 / 史正良门下 18 人 / 匹配 75/100 / 完整度 75%——全部来自 `web/public/data/chefs.json` meta 与界面实读，无编造。谱首凡例、卷内批注、片尾一致。
- 素材：真实头像 `web/public/portraits/`（178 张：元老 35 全量 + 缅怀 40 + 学院 16 + 名厨 5 + 资深 50 + 当代 48 + 史门 2）；谱页/社区真实截图作「影印」批注嵌入（03 / 10 两张）；18 位徒弟名单、陈波待补档案、周慕白口述原文、社区 5 帖均为产品真实数据。
- TTS 备忘：本机 edge-tts(aiohttp) 被服务端 TLS 指纹拦截、HeadlessChrome UA 被 403——改用自研 `tts_scenes_ws.js`（Node 裸 TLS + 手写 ws 帧 + Edge UA，协议逐字节对齐 edge-tts v7），音频与主版同源同参。

## 视觉密度条款（防线框稿）

1. **主角唯一**：每镜卷面活跃区块 ≤2（本镜特写区 + 相邻区残影），屏幕层标注 ≤2（大字/批注 + 字幕）；特写区外内容靠暗角与景深退让，不靠删改卷面。
2. **运动预算**：每镜显式三轴（dx/dz 单调），settle 后禁止归零——抽任意帧做 diff 必须有位移；镜 8 例外条款：推镜在 cue:ai 前完成，打字段期间仅保留 dz 0.15%/s 微推。
3. **一镜一主动效**：镜 5 只有朱圈；镜 6 只有光标；镜 11 只有收拢+落定。错峰入场不计入「主动效」。
4. **群像纪律**：谱首墙 178 张真实头像一次布满、靠点亮节奏演出；禁止对单张头像推近超过 1.3x（素材 1x）。
5. **文字全部有出处**：屏幕文字来自解说稿、产品界面原文或数据 meta；「先立真实」「宁可谱瘦，不让谱说谎」为导览批注层，用衬线+朱红与 UI 拉开一层。
6. **章法自检**：任意抽帧应满足——有界栏（卷面格线）、有竖排（题签/跋注）、有朱批（章/圈/签）、有留白（卷缝 ≥60px）。
