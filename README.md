# 星厨传承 · Star Chef

> 以「师承关系」为信任底层的厨师职业平台 —— 让手艺被看见，让每一位厨师都有出路。

**参赛项目**：TRAE AI 全国大学生创造力大赛 · **赛道三：社会公益丨造个助人的好工具**
**提交截止**：2026.12.25（官方论坛提交）· **决赛路演**：2027 年 1 月中旬

## 这是什么

帮中国两千万厨师里最弱势的群体——45+ 岁、不擅文书、依赖熟人网络的老师傅——把「师承」数字化为可记录、可搜索、可匹配的职业基础设施：

- **数字师承谱**：1,238 位真实厨师档案（853 位有头像、1,103 位可溯源），古籍宗谱式呈现门派—代际—师徒；
- **智能就业匹配**：多维可解释的双向推荐（菜系/师门/师承距离/地域/薪资）；
- **AI 求职助手**：大白话/语音描述经历 → 规范求职档案，严格按口述提取、不编造；
- **厨师社区**：同行切磋、师傅招徒、学徒请教。

## 运行

```bash
cd web
npm run dev        # http://localhost:5173/star-chef/ （node_modules 已装好）
npm run build      # 类型检查 + 构建到 web/dist/
npm run lint       # oxlint
```

## AI 能力（DeepSeek）

- Key 存浏览器 `localStorage`（`star-chef:deepseek-key`），仅本机、不上传、不入仓库；
- `/api/deepseek` 代理仅 `npm run dev` 生效；静态部署下在页面切换直连模式（受 CORS 限制）；
- **不配 Key 也能完整体验**：自动降级为本地规则演示，界面诚实标注「本地演示解析」。
